# Gulls Ticketing Command Center UI Refactor

This repository now contains a production-ready Next.js App Router dashboard scaffold for a premium command-center redesign, including:

- App shell + sidebar + header
- Sales Overview / Pacing & Leaderboards / Data Quality tabs
- Reusable KPI, chart, leaderboard, trust, and audit components
- Formatting helpers for currency/percent/compact numbers
- Data transformation helpers with clean typing
- Placeholder data wiring that can be swapped to static JSON or future Graph/SharePoint adapters

See `src/` for implementation.
